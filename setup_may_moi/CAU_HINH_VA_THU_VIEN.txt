BUOC 2: Tao file requirements tu file nay
  Vi da gop tat ca vao 1 file, can tach danh sach ra truoc khi cai.

  Danh sach o PHAN 7 va PHAN 8 duoc danh dau bang cac dong moc:
        #BEGIN312 ... #END312       (cho Python 3.12)
        #BEGIN311 ... #END311       (cho Python 3.11)

  CACH A - Thu cong (de nhat):
    1. Mo file nay bang Notepad
    2. Boi den toan bo danh sach o PHAN 7, nam GIUA hai dong #BEGIN312
       va #END312 (tu "aiohappyeyeballs==" den "zstandard==") -> Copy
    3. Dan vao Notepad moi -> Luu thanh: req312.txt
    4. Lam tuong tu voi PHAN 8 (giua #BEGIN311 va #END311)
       -> Luu thanh: req311.txt

  CACH B - Tu dong bang PowerShell (nhanh hon, khuyen dung):
    Mo PowerShell tai thu muc chua file nay, dan nguyen khoi lenh sau:

        $f = Get-Content ".\CAU_HINH_VA_THU_VIEN.txt"
        foreach ($v in @("312","311")) {
            $b = ($f | Select-String "^#BEGIN$v$").LineNumber
            $e = ($f | Select-String "^#END$v$").LineNumber
            $f[$b..($e-2)] | Out-File "req$v.txt" -Encoding utf8
            "Da tao req$v.txt ($($e-$b-1) goi)"
        }
